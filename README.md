# FUJIN-P

FUJIN-P（Fukuchiyama Universal Joint Information Nexus – Prototype）は，小規模大学におけるDX推進を目的とするFUJIN-Pの参照実装です．Flask と MySQL で書かれた，アプリを束ねる基盤（カーネル）と，その上で動く31本のアプリからなります．

PythonAnywhere の有料プラン（Developer 以上）を想定した規模です．MySQL を全面的に使うため，無料枠では動きません．職員が自分のサイトを立ち上げ，自分の業務に必要なアプリを生成AIの助けを借りて作り，そのまま同僚に提供する．そういう使い方を想定しています．

どうぞ複製して活用してください．

## 何が入っているか

カーネルは，認証，ユーザ管理，アプリの登録簿（アプシャ）からなります．アプリの起動とダッシュボードのカードは `fujinp/app_registry.json` を正本として組み立てられるので，アプリを足すときに `app.py` やダッシュボードのHTMLを手で書き換える必要はありません．

アプリは `fujinp/` の下に1本ずつ入っています．文書の共同執筆，会議の議事録，研究倫理審査のワークフロー，時空資源の予約，データの可視化など，大学の業務から生まれたものが並びます．どれも同じ作法で書かれているので，1本読めば他も読めます．

## 立ち上げ方

新しいサイトを立ち上げる手順は，アプリ「まいあし」（`fujinp/migration_assistant/`）に同梱しています．`data_for_distribution/` の3本の手引きが，データベースの用意から最初の管理者の登録までを案内します．

必要なのは，PythonAnywhere（または同等の Python が動くホスティング），MySQL，そして `config.py` の記入だけです．`config.py` はこのリポジトリに含まれません．`config_template.py` を写して使ってください．
