名寄せ（氏名 → ユーザ）

  
自動で紐づくのは，users の氏名と完全一致するもの（空白・括弧は無視）と，名簿の氏名からメール経由で一意に決まるものだけです．姓だけの表記は曖昧なので自動では紐づけません．ここで人を選んで「紐づけ」を押すと，その氏名の発令をまとめて結びつけます．users に登録のない外部の方は「対象外」にすると一覧から消えます（下の一覧で解除できます）．

アカウント名簿（人 → ログインできる人）

  
台帳が正です．ここで人を足す・直す・消すと，users に直ちに反映されます（自分自身と最後の admin は降格・削除しません）．メール未記入の人は先頭に出ます（右端の「編集」で直せます）．「発行」を押すと，有効期間内でまだ users にいない人を approved_users に写し，期限切れの人を approved_users から外します．approved_users にある人は初回ログインでアカウントが作られます．「users まで作る」を付けると，ログインを待たずに users を直接作ります（実験段階向け）．既にある users は触りません（退職者の停止はユーザ管理で）．発行後は名寄せを自動で掛け直します．Google を使わない人には 🔑 でパスワード設定メールを送れます（本人が「パスワードを忘れた方」から自分で設定することもできます）．

  

    
    
    
    
    
    
    
    
  

  

  







  
グループ定義（台帳 → user_groups）

  
台帳が正です．「台帳を users・user_groups 等に反映する」を押すと，名簿から users と approved_users を揃え，名寄せを掛け直し，台帳の全単位について user_groups とルールを揃えます．何度押しても同じ結果になり，既にあるグループは名前も直接メンバーもそのままで，不足しているルールだけを足します．「候補」から作ると，台帳のグループ種別はその名前のまま，組織の学部等は「◯◯教員」，事務局の課・係はその名前，会議体は「◯◯」（委員側）と「◯◯_事務」（事務職員）の2つができます．同名のグループが既にあれば，そこにルールを足すだけです．

  

    
    
    
    
    
    
    
  

  

  







  
登録申請とブラックリスト

  
名簿にない人からの登録申請です．「承認」は名簿に載せて users を直ちに作ります（区分は申請どおり，ここで変えられます）．「ブラックリスト」はその後の申請とログインを止めます（users があれば無効化）．
