永続IDの起点とサイト移行用の書き出し

このサイトを永続IDの起点にすると，その時点のユーザとグループのうち永続IDの無いものに発番します．以後は書き出すたびに，新しく増えたユーザとグループにも発番します．接頭辞は，一度発番すると変えられません．

接頭辞

ユーザ（登録申請・ブラックリストを含む），システムグループと直接メンバー，組織ツリー（ノード・親子・メンバーシップ・立場），導出ルールと対応付け，名簿，永続IDを1本のファイルに書き出します．

サイト移行用の取り込み

ほかのサイトで書き出した JSON を取り込みます．ユーザは永続ID，次にメールで突き合わせ，一致したユーザはこのサイトの行をそのまま使います（admin などの区分も変わりません）．新しく作るユーザのうち区分 admin の人は regular になります．グループは永続ID，次に名前で突き合わせます．同じ名前のグループは，統合するか別名で残すかを選べます．「確認」は取り込みを最後まで試してから取り消すので，出てくる件数は「取り込む」と同じです．

ノードとシステムグループの対応付け（例外管理）

組織ツリーのノードには，作ったときに同名のシステムグループが1対1で付きます．ここでは，システム構築上の事情で名前が違うもの・対応のないもの・複数付いているものを admin が直します．組織情報管理の画面には，ここでの結果が表示だけされます．

グループ管理統括の任命

グループ管理統括は，グループの改廃（作成・改名・廃止）とグループ管理者の任命を行います．任期はなく，解任するまで続きます．台帳では予約単位「グループ管理統括」のメンバーとして記録され，サイト移行用の書き出しで他のサイトへも運ばれます．admin が統括を兼ねるときは，ここで自分を任命してください．
