保存対象のディレクトリ

アプリ名とディレクトリは書き換えて「更新」で保存できます．保存記録は「💾 Save」を押した日時で，表示のみです．
「💾 Save」を押すと，そのディレクトリの中身を zip にしてダウンロードします（ファイル名は ID_日時.zip）． ディレクトリは絶対パスで書きます．… の外（ホーム直下の static/mdimgs など）も登録できます．

Inspect と Restore

Data Saver で保存した zip を選んで「🔍 Inspect」を押すと，どの ID・アプリ・ディレクトリのものかを表示します．この時点ではファイルは変わりません．
「♻️ Restore」は，zip に記録された ID の行が指すディレクトリへ上書きで展開します．zip に無い既存ファイルはそのまま残ります．

Claude 向け一括調査

「依頼文を作る」を押すと，このサイトの全アプリ（…）を対象に，データ置き場を調べて表を正しい内容に直すよう頼む依頼文を作ります． 依頼文には現在の表（ID付き）が入っており，Claude は ID を引き継いだ JSON を返します． 「📋 コピー」で写し，ソース一式（またはアプリパッケージ）と一緒に Claude に渡してください．

調査結果の照合と反映

Claude の返事をそのまま貼り付けて「照合」を押すと，表と突き合わせて追加・訂正・削除の候補を示します（この時点では表は変わりません）． JSON のほか，アプリ名⇥絶対パス⇥根拠⇥説明 の形のタブ区切りテキストも読めます（先頭に ID 列があってもかまいません）．
削除の候補になるのは，結果に出てきたアプリの行のうち照合されなかったものだけです．結果に出てこなかったアプリの行には触れません．
