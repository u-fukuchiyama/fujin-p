            2 スキーマ同梱データベースの選択
            チェックしたデータベースの CREATE TABLE 定義を， データベースごとに schema_<名前>.sql （例: schema_default.sql，schema_fujinp.sql） としてパッケージに同梱します。 テーブル定義のみで、データ（行）は含まれません。
            {% if allow_guest_download %}
            📢 現在このサイトは、ログイン済みユーザー全員が パッケージをダウンロードできる設定です （ALLOW_GUEST_DOWNLOAD = True）。
            ソース公開（AGPL 等）を目的としたパッケージを作る場合は、 チェックをすべて外すことをおすすめします。 ソースコードの頒布にデータベース構造は必要なく、 同梱すると内部構造まで公開することになります。 移設のためのパッケージであれば、必要な DB にチェックを入れてください。

            3 config_template.py のレビュー・確定
            ⚠️ 下のエディタは config.py を自動で匿名化したものです。 秘密情報が伏せ字（<YOUR_...>）になっているか必ず確認し、 必要な修正をこの場で直接おこなってください。 手順は 編集 → 💾 保存 → ✔ 確認 です。 確認まで終えると、その内容が config_template.py として パッケージに同梱されます。
            config_template.py ✏️ 編集中 ● 未保存の変更があります
            内容を確認・修正したら「💾 保存」を押してください。
            4 パッケージの登録
            パッケージの説明（自由テキスト） ＊必須
            ⚠️ パッケージの説明が未入力です。登録するには説明を入力してください。
            登録すると ZIP が生成され、日付・説明とともにシステムに保存されます。 登録後はインポーターからダウンロードできます。
            ※ 登録するには、ステップ3で config_template.py の「✔ 確認」 を完了しておく必要があります。
