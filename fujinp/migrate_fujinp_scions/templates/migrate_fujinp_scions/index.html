さいまる

FUJIN-P マイグレーション支援ツール
🏠 FUJIN-Pダッシュボードに戻る
「さいまる」は FUJIN-P サイトを別環境へ移行するためのツールです。 エクスポーターでサイトを丸ごとパッケージ化して登録し、 インポーターで登録済みパッケージを受け取ります。
{% if is_admin %}
📦
エクスポーター admin 専用
実行母体の FUJIN-P サイトを丸ごとコピーした エクスポートパッケージを作成・レビュー・登録します。 移行元サイトの admin が使用します。
{% else %}
📦
エクスポーター admin 専用
パッケージの作成・登録はサイトの admin のみが行えます。 パッケージの用意が必要な場合は admin にご連絡ください。
{% endif %} {% if can_download %}
📥
インポーター{% if not allow_guest_download %} admin 専用{% endif %}
登録済みのエクスポートパッケージを一覧から選び、 ZIP ファイルとしてダウンロードします。
{% else %}
📥
インポーター admin 専用
パッケージにはサイト全体のソースコードが含まれるため、 一覧・ダウンロードは admin のみに限定されています。 パッケージが必要な場合は admin にご連絡ください。
{% endif %}
{% if not is_admin and not can_download %}
🔒 現在の設定では、さいまるの機能はサイトの admin に限定されています。 配布範囲を広げる場合は、サイト管理者が routes.py の ALLOW_GUEST_DOWNLOAD を True に変更します。
{% endif %}
