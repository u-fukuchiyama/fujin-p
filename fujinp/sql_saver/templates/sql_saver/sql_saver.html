対象データベースを選択

選択したデータベースの全テーブルを「CREATE文 + 全行データ」を含む JSON として書き出し、 1つの zip にまとめてダウンロードします。zip は手元のPCに保存してください。 zip には users テーブル（メールアドレス・パスワードハッシュ）も含まれます。
DB一覧を読み込み中...

サーバ上の作業ファイルを削除

zip を手元のPCにダウンロードして確認したら、こちらでサーバ上の作業ファイルを 全て削除できます（ダウンロード済みの zip も含めて全消去）。 情報を残さないため、確認できしだい実行してください。

バックアップ zip をアップロード

手元の zip をアップロードすると中身を解析します。復元は完全置換 （該当テーブルを削除してから作り直し）です。実行前に上書き対象を一括確認します。

復元内容の確認

復元したいデータベースとテーブルにチェックを入れてください。 赤=上書き(既存削除) / 緑=新規作成 / 灰=対象外DB / 橙=名前が不正（復元不可）

操作履歴

バックアップ・リストア・作業ファイル削除の実行記録です（新しい順）。 記録先は sql_saver_audit テーブルです。
