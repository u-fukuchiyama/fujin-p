API エンドポイント（参照用）

他のアプリからこのアプリの権限を確認するためのAPIです。

GET /admin/api/user/{'{user_id}'}/app/{{ app.id }}/permissions

ユーザが持つフィーチャーに基づき、このアプリで許可された権限ラベルの一覧をJSON形式で返します。
