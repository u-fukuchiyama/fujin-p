## 別サイトへのインストール — 全体マニュアル

新品の PythonAnywhere に FUJIN-P を立ち上げ，アプリを載せるまでの道筋です．作業は2つの段階に分かれます．

第1段階で，カーネルとアプシャだけの「種」を立ち上げます．終わると，admin でログインして管理者ダッシュボードが出て，そこにアプシャのカードがある状態になります．アプリはまだ1本も入っていません．

第2段階で，そのアプシャを使ってアプリを1本ずつ取り込みます．ユーザの移行もアプリとして取り込みます．

段階の間に，人が手で行う設定がいくつか挟まります．これを α と呼んでいます．データベースの作成，`config.py` の記入，WSGI の設定，最初の admin の登録の4つです．自動化できるところは自動化してあるので，手で行うのはこれだけです．

## 全体の流れ

```
  ┌─ 第1段階 ─────────────────────────────┐
  │  fujinp_kernel_install.py --files      ← ファイル展開（自動）
  │  α  データベースを作る                   ← 手動
  │  α  config.py を書く                    ← 手動
  │  fujinp_kernel_install.py --schema     ← テーブル作成・正本の発行（自動）
  │  α  WSGI を設定して Reload              ← 手動
  │  α  最初の admin を登録                 ← 手動（make_admin.py が文を作る）
  └────────────────────────────────────────┘
            ↓  admin でログインできる／アプシャが動く
  ┌─ 第2段階 ─────────────────────────────┐
  │  配布元でアプリを 📦 エクスポート          ← JSON を1本受け取る
  │  こちらのアプシャで取り込み（検証→適用）    ← 自動
  │  必要なら config.py に定数を足す          ← 手動
  │  Reload                                  
  │  （アプリの数だけ繰り返す）                
  └────────────────────────────────────────┘
```

## 所要時間の目安

第1段階が 30 分ほどです．初めての人でも，つまずくのは `config.py` の記入と WSGI の設定の2か所に限られます．どちらも書く場所と書く内容が決まっています．

第2段階は，アプリ1本あたり5分ほどです．取り込む順は自由ですが，他のアプリから使われるもの（まいぐる＝ユーザとグループ）を先に入れると，あとが楽になります．

## 用意するもの

PythonAnywhere のアカウント（無料プランで動きます）．Web タブで Flask の Web アプリを1つ作っておきます．Python は 3.10 以上を選びます．

`fujinp_kernel_install.py` を1本．この画面からダウンロードできます．

アプリのパッケージ JSON．第2段階で使います．配布元のサイトのアプシャで，アプリごとに 📦 エクスポートして作ります．

## 何が入っていて，何が入っていないか

`fujinp_kernel_install.py` には，カーネル（`app.py`・認証・データベース接続・共通テンプレート・アカウント管理・ゲストダッシュボード）とアプシャが入っています．51 ファイルです．

`config.py` は入っていません．秘密情報を持つファイルなので，各サイトで書きます．代わりに `config_template.py` が入っていて，埋める場所は6か所です．

アプリは1本も入っていません．すべて第2段階で取り込みます．

## 段階ごとの手引き

第1段階の手順は「第1段階マニュアル」に，第2段階の手順は「第2段階マニュアル」に，それぞれ順を追って書いてあります．画面の上のボタンから開いてください．

うまくいかないときは，まずその段階のマニュアルの末尾にある確認順を見てください．
